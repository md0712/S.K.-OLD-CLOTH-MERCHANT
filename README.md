## 🌟 Overview
S.K. Old Cloth Merchant is a modern, high-end B2B and retail used clothing supplier website and business suite designed specifically for an established wholesale merchant in Choolai, Chennai.

Built with **React.js, Vite, Tailwind CSS, Lucide Icons, Express.js REST API**, and featuring photography directly derived from the supplier's warehouse and bale inventory.

---

## 📁 Repository Structure
```
sk-old-cloth-merchant/
├── frontend/             # Customer-facing React 19 website
├── backend/              # Express REST API with rate-limiting, JWT & validation
├── admin/                # Administrator management portal
├── database/             # Relational MySQL schema, seed data, & migrations
└── docs/                 # Technical & deployment documentation
```

## 🚀 Running the Project

### 1. Customer Website (Frontend)
```bash
cd frontend
npm install
npm run dev
```
Runs at: **http://localhost:5173**

### 2. Express Backend API
```bash
cd backend
npm install
npm start
```
Runs at: **http://localhost:5000** (Health check: `/api/health`)

### 3. Administrator Dashboard
```bash
cd admin
npm install
npm run dev
```
Runs at: **http://localhost:5174**
